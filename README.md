# SmotrimHub

SmotrimHub - это NodeJS приложение, которое парсит каналы с `streamlive.freedev.app` и сохраняет их копии для долгосрочного хранения и SEO оптимизации. Приложение автоматически обновляет информацию о просмотрах и расписании, а также добавляет новые каналы каждые 30 дней.

## Установка

1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/YOUR_USERNAME/SmotrimHub.git
    cd SmotrimHub
    ```

2.  Установите зависимости:
    ```bash
    npm install
    ```

3.  Настройте переменные окружения (если необходимо):
    Создайте файл `.env` в корне проекта и добавьте необходимые переменные, например:
    ```env
    SOURCE_URL=https://streamlive.freedev.app
    SAVE_INTERVAL_DAYS=30
    LOG_LEVEL=info
    ```

## Запуск

Для запуска приложения в режиме разработки:

```bash
node index.js
```

Для запуска в продакшене рекомендуется использовать менеджер процессов, например PM2:

```bash
npm install -g pm2
pm2 start index.js --name smotrimhub --watch
```

Для запуска на Vercel, убедитесь, что у вас настроен `vercel.json` (если требуется специфичная конфигурация, иначе Vercel сможет запустить `npm start` автоматически).

## Как это работает

Приложение выполняет следующие задачи:

*   **Парсинг каналов:** Регулярно запрашивает данные о каналах с `streamlive.freedev.app`.
*   **Сохранение контента:** Каждые 30 дней создает и сохраняет копии каналов, оптимизированные для поисковых систем.
*   **Синхронизация:** Обновляет информацию о просмотрах и расписании с источника.
*   **Добавление новых каналов:** Периодически (каждые 30 дней) ищет и добавляет новые каналы, появившиеся на источнике.
